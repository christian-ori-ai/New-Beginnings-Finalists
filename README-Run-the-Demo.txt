Run the Demo Site (No Hosting Needed)

Put these launcher files in the same folder as index.html.

LOCAL DEMO (THIS COMPUTER):
MAC:
1) Double-click: START_DEMO_MAC.command
2) Terminal opens and your browser opens to the demo.
3) To stop: close the Terminal window.

WINDOWS:
1) Double-click: START_DEMO_WINDOWS.bat
2) Browser opens to the demo.
3) To stop: close the Command Prompt window (or press Ctrl + C).

MOBILE VIEWER (PHONE/TABLET ON SAME WI-FI):
1) Mac: double-click START_MOBILE_DEMO_MAC.command
2) Windows: double-click START_MOBILE_DEMO_WINDOWS.bat
3) Use the printed URL on your phone browser.

Notes:
- v8 uses ports 8080 to 8089.
- Every version has its own port range so all versions can run at the same time.
- Mobile launchers bind to your local network (0.0.0.0) so other devices can open the demo.
- These launchers serve whichever folder they are in.
