WordPress-Style Demo

Homepage editor sample

This demo only affects the homepage preview in this browser. It is built to show how a very simple owner editor could work without exposing the rest of the site.

Section 1

Content

Edit just the homepage copy to start. The hero title supports simple HTML like <em>.

Section 2

Typography

Adjust a few key text systems instead of every single element.

Section 3

Tiles & Panels

Try different card and quote-panel treatments to show how easy visual updates could be.

Section 4

Images

Paste a full image URL, use a site-relative path like images/photo.avif, or try a local upload just for the preview.
